Прием и обработка векторов от клиента

Прием и обработка векторов данных от клиента

Возвращает
true если обработка успешна, false в противном случае
true если обработка успешна, false в противном случае

Выполняет следующие шаги:

  1. Прием количества векторов
  2. Для каждого вектора:
    • Прием размера вектора
    • Прием данных вектора
    • Вычисление произведения элементов
    • Отправка результата клиенту
